# Backend PHP (chưa triển khai)

Thư mục này dự kiến chứa các file PHP xử lý phía server, ví dụ:

- `login.php` — xử lý đăng nhập, nhận POST từ [auth.js](../assets/js/auth.js)
- `register.php` — xử lý đăng ký, nhận POST từ [auth.js](../assets/js/auth.js)
- `order.php` — lưu đơn hàng, nhận POST từ [checkout.js](../assets/js/checkout.js)
- `contact.php` — lưu liên hệ, nhận POST từ [contact.js](../assets/js/contact.js)
- `products.php` — (tùy chọn) thay thế `data/products.json` bằng dữ liệu từ database
